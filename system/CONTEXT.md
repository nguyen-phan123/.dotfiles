# ⚙️ System Utilities Context (system/CONTEXT.md)

Domain vocabulary for OS-level configurations, keymapping, security tools, and Python packaging.

## Vocabulary & Core Concepts

### 🔑 GPG Signing Agent (`gnupg`)
*   **Definition**: GnuPG agent setup and configuration stowed under `system/gnupg/` mapping to `$HOME/.gnupg/` for git commit signing.
*   **Target terms**: Use **GPG Signing Agent**.

### ⌨️ Karabiner Keymap (`karabiner`)
*   **Definition**: Karabiner-Elements profile and complex modifications stowed under `system/karabiner/` mapping to `$HOME/.config/karabiner/`.
*   **Target terms**: Use **Karabiner Keymap**.

### 🐍 Pip & UV Config (`pip`, `uv`)
*   **Definition**: Python package manager settings and mirror configurations stowed under `system/pip/` and `system/uv/`.
*   **Target terms**: Use **Pip/UV Config**.
