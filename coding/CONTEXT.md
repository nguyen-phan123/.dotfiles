# 💻 Coding Environment Context (coding/CONTEXT.md)

Domain vocabulary for code editors and IDE configurations (Neovim, LunarVim).

## Vocabulary & Core Concepts

### ⚡ Neovim Config (`nvim`)
*   **Definition**: Custom Neovim configuration directory stowed under `coding/nvim/` mapping to `$HOME/.config/nvim/`.
*   **Target terms**: Use **Neovim Config**.
*   **Avoid**: *Vim setup*, *raw neovim*.

### 🌙 LunarVim Config (`lvim`)
*   **Definition**: LunarVim IDE configuration directory stowed under `coding/lvim/` mapping to `$HOME/.config/lvim/`.
*   **Target terms**: Use **LunarVim Config**.

### 🔒 Lazy Lockfile (`lazy-lock.json`)
*   **Definition**: The plugin lockfile generated by Lazy.nvim to ensure deterministic editor plugin versions.
*   **Target terms**: Use **Lazy Lockfile**.
